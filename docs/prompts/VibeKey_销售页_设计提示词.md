# VibeKey 销售页 — 设计提示词

> 目标风格参考：doubleyoumanagement.net（land-book.com 获奖站点）  
> 核心受众：Claude Code "Yes 功能" 用户 —— AI 编程重度使用者

---

## 设计策略 Prompt

```
设计一个 VibeKey 机械键盘销售落地页，风格参照 doubleyoumanagement.net：

【整体调性】
- 暗黑基调为主（#0a0a0a 到 #111），穿插奶白色块制造反差
- 粗野主义 × 精致极简 —— 大胆的排版 + 克制的细节
- "这是键盘，但不止是键盘" —— 把它当奢侈品单品来做

【排版系统】
- 标题：超大号无衬线（clamp(3rem, 8vw, 7rem)），极紧字间距，全大写或中文留空
- 正文：中号衬线体（Noto Serif SC / Georgia），宽松行距（1.8-2.0）
- 数字/价格/参数：等宽字体（JetBrains Mono / SF Mono），强调精确感
- 大量留白 —— 段落之间至少 120px 间距

【配色方案】
- 主背景：深黑 #0a0a0a
- 文字：暖白 #f5f0e8（不是纯白，带温度）
- 强调色：暖金 #c4a87c（按钮、hover、点缀线）
- 次级背景：奶油白 #f8f4ed（产品卡片区域，制造切换）
- 极客模式：纯黑 #000 + 紫青渐变（RGB 光效区域）

【动效设计】
- 滚动触发：元素从下方 60px 淡入上浮（opacity + translateY）
- 视差：产品图片随滚动微移
- 悬停：图片微放大(1.03) + 边框亮起
- 页面切换感：每个 section 是一个 "屏幕"，scroll-snap 吸附
- 光标：在键盘展示区变成放大镜或光束

【首屏英雄区】
- 全屏视频背景（嵌入 VibeKey 介绍视频）
- 视频上方叠加大号标题："为 AI 编程而生"
- 底部一个向下的呼吸箭头指示滚动
- 视频结束后自动淡入标题

【产品展示区 —— 六款配色】
- 左右交替布局（Z 字形扫描）
- 左图右文 → 左文右图 → 循环
- 每款一个独立 "画布"，背景为该配色的情绪色
- 大图展示 + 配色名称 + 一句情绪文案
- 悬停时图片微动（Ken Burns 效果）

【"Yes 功能" 专属卖点区】
- 深黑背景 + 代码风格排版
- 模拟 Claude Code 对话界面展示 "Yes" 按钮
- 文案："当你敲下 Yes，VibeKey 也在回应你"
- 卖点卡片：机械轴体反馈、PBT 键帽触感、RGB 状态指示

【技术规格区】
- 极简表格，无边框，只有细线分隔
- 类似 Apple 产品页的 spec 区
- 等宽字体参数列表

【CTA 转化区】
- 全宽暖金色块，打破暗黑基调
- 大字："选一款，开始你的 AI 编程之旅"
- 六色选择器 → 点击跳转购买

【Footer】
- 极简，只有品牌名 + 一行小字
- "VibeKey — 为触感而生。为 AI 编程而造。"
```
