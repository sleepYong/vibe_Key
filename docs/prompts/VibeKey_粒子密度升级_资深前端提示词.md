# VibeKey 粒子密度升级 — 资深前端执行提示词

## 诊断

| 问题 | 根因 | 修复方向 |
|------|------|----------|
| 上升粒子太少 | 仅 120 颗，散布在 4K viewport 中 | 300 颗，缩小体积，形成"火星升腾"密度 |
| 粒子体积太大 | radius 0.8-2.8px + glowR 3.5× = 可见直径 ~20px | radius 0.3-1.2px，glowR 2× |
| 流星远低于预期 | max 15 + 0.3-0.8s 间隔 = 视觉上仍稀疏 | max 30 + 0.05-0.2s 生成 + 爆发频繁化 |

## 执行清单

### 1. 上升光粒
```
数量：120 → 300
体积：r 0.8-2.8 → 0.3-1.2（微尘感）
光晕：glowR 3.5× → 2×（缩小光斑）
颜色：保持暖金/暖白/淡青/淡紫比例
浮动：vy 加速 20%（升得更快，循环更快）
```

### 2. 萤火虫
```
数量：70 → 100
体积：r 0.7-2.8 → 0.4-1.5
光晕：glowR 5.5× → 3×
```

### 3. 流星雨（核心改动）
```
上限：15 → 30
生成间隔：0.3-0.8s → 0.05-0.2s（几乎连续）
常规补充：setInterval 350-850ms → 150-350ms
爆发：2-4颗/3-5s → 4-8颗/1.5-3s
辐射点：保持右上角
火流星概率：8% → 12%
```

### 4. 新增：流星群批量生成
```
启动时一次性生成 8-12 颗流星，
让用户第一眼就看到流星雨的密度。
之后靠定时器维持密度。
```

## 预期效果

```
画面右上角持续有流星拖尾划过——
不是"偶尔一颗"，而是"同时能看到 5-8 条尾迹"。
光粒如火星从底部升腾，细小而密集。
萤火虫如微尘在整个画面漂浮。
整体视觉：代码宇宙中的粒子风暴。
```
