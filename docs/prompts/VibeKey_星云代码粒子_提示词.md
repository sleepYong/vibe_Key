# VibeKey — 香槟金+灰蓝星云 + 代码粒子 + 四角柔光

## 一、香槟金 + 灰蓝色弥散星云

```
在现有 cosmos-nebula 基础上新增两个专门色系星云层：

Layer A: 香槟金色弥散星云
- 2 个巨型 radial-gradient 光斑
- 颜色：rgba(196,168,124,0.06) — 香槟金，极低透明度
- 位置：左上区域 + 右下区域，各覆盖 40-50% 画面
- 动画：独立 45s / 55s 周期漂移

Layer B: 灰蓝色弥散星云
- 2 个巨型 radial-gradient 光斑
- 颜色：rgba(140,155,180,0.05) — 灰蓝，极低透明度
- 位置：右上区域 + 左下区域，与香槟金交错
- 动画：独立 50s / 60s 周期漂移
```

## 二、半透明浅绿色代码粒子

```
新增 Canvas 粒子层：
- 数量：60 颗微型代码粒子
- 颜色：rgba(180,210,190,0.15-0.35) — 浅绿色半透明
- 大小：0.4-1.0px
- 形态：微小光点，部分呈竖线形（模拟代码字符的抽象形态）
- 运动：极其缓慢地沿对角线方向漂移（模拟随星轨移动）
  - vx: -0.05 到 -0.2 px/帧（缓慢向左）
  - vy: -0.03 到 -0.15 px/帧（缓慢向上）
- 分布：空白背景区域（避开产品图片和信息面板区域）
- 部分粒子偶尔微微闪烁（sin 波，周期 3-6 秒）
```

## 三、四角淡金色呼吸柔光

```
四个角落各一个 CSS radial-gradient 光晕：
- 左上角：ellipse 30% 30% at 0% 0%
- 右上角：ellipse 30% 30% at 100% 0%
- 左下角：ellipse 25% 25% at 0% 100%
- 右下角：ellipse 25% 25% at 100% 100%
- 颜色：rgba(196,168,124,0.04-0.08) — 淡金色
- 动画：呼吸效果，4 秒周期 opacity 在 0.03-0.07 之间脉动
- 四角相位错开（各差 90°），制造此起彼伏的环绕感
```

## 四、实现方式

```
CSS 层：
- .cosmos-champagne — 香槟金星云（新增）
- .cosmos-slate — 灰蓝星云（新增）
- .cosmos-corners — 四角柔光（新增）
全部放在 cosmos-global 容器内，z-index 在 deep/nebula 之上，canvas 之下

Canvas 层：
- 在现有全局 canvas 中新增 codeParticles 数组
- 60 颗，独立渲染循环
```

## 五、预期效果

```
原本的深色空白区域现在有了层次感——
香槟金色的暖光在左上和右下若隐若现，
灰蓝色的冷光在右上和左下与之交错。
四角有淡金色的呼吸光晕，如画框般环绕整个画面。
60 颗浅绿色微型代码粒子在背景中极缓慢飘移，
仿佛代码本身化作了星尘。
```
